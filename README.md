## Описание проекта

MoneyTrack — Telegram-бот для управления личными финансами.

Бот позволяет учитывать доходы и расходы, распределять
операции по категориям, контролировать бюджет и
просматривать финансовую статистику.

## Планируемый функционал

- Добавление доходов и расходов.
- Хранение финансовых операций в SQLite.
- Категории расходов.
- Расчёт текущего баланса.
- Установка месячного бюджета.
- Просмотр финансовой статистики.
- Напоминания о платежах.
- Финансовые советы.

## Технологии

- Python
- python-telegram-bot
- SQLite
- Telegram Bot API
